# SPA

## Advantages
- Fast navigation
- No full page refresh
- Better user experience
- Smooth transitions between views
- Reduces repeated HTML downloads
- Makes SPAs feel like native applications

## Limitations
- Initial bundle download can be larger.
- Search engine optimization (SEO) can be more challenging unless techniques like server-side rendering (SSR -  e.g NextJS) or static site generation (SSG) are used.
- Users may briefly see a loading state while JavaScript initializes.
